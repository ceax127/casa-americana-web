# Casa Americana · Premium Construction

Preview website for **Casa Americana**, a builder of American-style homes in Cajamarca, Peru.

- **Single Family House**: premium American homes on your own land.
- **American Style Building**: boutique luxury residences with a shared rooftop.
- Every project stands on a 100% steel, earthquake-resistant structure.

## Structure

```
index.html          The whole site (HTML + CSS + a little JS)
assets/logo.svg     Horizontal logo
assets/isotipo.svg  Logo mark (favicon, social media)
assets/img/         Photos
```

It is a static site with no build step. Open `index.html` in a browser, or host the folder on GitHub Pages, Netlify or Cloudflare Pages.

## Before going live

- Prices, sizes, unit counts, phone, email, address and the testimonial are placeholders.
- Photos are reference images from [Unsplash](https://unsplash.com) (Unsplash License). Replace them with real project photos or renders.
- The contact form only shows a confirmation message. Connect it to a form service (for example Netlify Forms) to receive leads.
